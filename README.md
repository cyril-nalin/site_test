🎯 Objectif

Le projet site_test a pour objectif de créer une première page web afin de découvrir et mettre en pratique les bases du développement web.

🛠️ Technologies utilisées
HTML — structure et contenu de la page web
CSS — mise en forme et présentation de la page

📁 Arborescence du projet

L'organisation du projet est volontairement simple afin de faciliter la compréhension des premiers concepts du développement web :

```text
site_test/
│
├── images/
│   └── ThePhantomPain.jpg   # Image utilisée dans le projet
│
├── index.html               # Page principale du site
├── style.css                # Feuille de style CSS
└── README.md                # Documentation du projet
```

📄 Description des fichiers et dossiers

* **`index.html`** : contient la structure et le contenu de la première page web.
* **`style.css`** : contient les règles CSS permettant de mettre en forme la page HTML.
* **`images/`** : dossier contenant les images utilisées dans le projet.
* **`images/ThePhantomPain.jpg`** : image utilisée dans la page web.
* **`README.md`** : présente le projet, son objectif, les technologies utilisées, son utilisation et les liens utiles.


🚀 Utilisation

Le projet est développé et exécuté à l'aide de Live Server.

Pour lancer le projet :

Ouvrir le projet dans un éditeur de code.
Installer ou utiliser l'extension Live Server.
Ouvrir le fichier index.html avec Open with Live Server.
La page web s'ouvre automatiquement dans le navigateur.

Le projet a été testé avec le navigateur Microsoft Edge.
